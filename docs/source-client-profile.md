# Bounded source client verification profile

This increment implements the `v1` pull transport in `src/lib/source.ts`. It is deliberately not an observer coverage certificate. `discoverFeedHead` verifies the operator's independently pinned dual-signed anchor, structurally parses the source's checkpoint, and labels the target `provisional: true`. It does not authenticate a rotated checkpoint signer or accept history. The later poller must replay every checkpoint and leaf against the pinned authority state before advancing a durable cursor.

The client uses the three fixed-target GETs in `docs/source-pull-contract.md`, exact canonical JSON envelopes and inner bytes, immediate predecessor checks, contiguous leaf positions derived from the request cursor, decoded streaming byte caps, timeouts, and redirect rejection. HTTP errors expose status without source response bodies; failures do not write observer state. No source credential convention or production secret was added while that decision remains pending.

The poller can distinguish `SourceHttpError` (status), `SourceTransportError` (connection, interrupted body or timeout) and `SourceProtocolError` (malformed successful response, including canonical/shape errors and decoded size limits). These errors contain no response body or source URL. A protocol error is source nonconformance, not proof of an authenticated fork; a transport error keeps coverage pending.

`test/source-fixture.ts` is a loopback HTTP transport fixture with a real dual-signed anchor, provider-signed checkpoints and canonical Merkle-rooted bytes. Its two placeholder leaves are **not governance actions or revisions** and must not be used to claim an authenticated governance replay. The fixture override supports malformed pages, outages, delay, old heads and alternate heads. A later full-governance fixture must replace those leaves and drive the published replay API after the observer authority dependency is updated.

Test-first evidence: the first focused run failed because `src/lib/source.ts` was absent. After implementation, disabling the nonterminal-checkpoint-page guard caused the targeted test to fail because an empty page resolved; restoring the guard made it pass. The classification tests then failed with the prior generic errors; changing the malformed-200 branch to a transport error made the targeted test fail again, and restoring it passed. On 2026-10-14, the full test, lint, typecheck, build and diff gates passed. The source suite exercises the real HTTP fixture, including a gzip body that expands beyond the decoded checkpoint cap. No deployed Vercel or real 1bridge source endpoint smoke was run.
